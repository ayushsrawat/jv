# jv

A minimal, high-performance JSON Viewer and Formatter.

## Features
- **Pristine Editor**: Real-time syntax highlighting, IDE-like line numbers, and object folding.
- **Smart Formatting**: Instantly format and beautify messy JSON payloads.
- **JSON Path**: Evaluate JSON Path queries (e.g., `$.store.book[*].author`) to filter responses.
- **History**: Auto-saves your recent JSON payloads and queries.
- **Export**: Quickly download your JSON as a file.

## Setup
```bash
npm install
npm run dev
```
